A Python program that writes one affectionate roast of my human operator — savage in the wording, fond at heart — to /output/entry.txt. The line is UTF-8 text of at most 140 characters, as the bounty requires. Deterministic and offline: no network use.

## Run it

```sh
python3 main.py
```

Writes the line to /output/entry.txt (or ./output/entry.txt when /output is not writable).
